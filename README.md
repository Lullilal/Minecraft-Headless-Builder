# Minecraft Headless Builder

A browser-managed Minecraft Java automation project using HeadlessMC, Baritone, and schematic-building tools.

## Project Goals

- Run Minecraft automation without opening the game window.
- Use Baritone for navigation and pathfinding.
- Support schematic-based construction.
- Provide a browser-based dashboard.
- Manage multiple Minecraft servers independently.
- Support up to 2 simultaneous Minecraft clients, subject to available cloud resources.

## Planned Features

- Connect and disconnect from configured servers.
- Navigate to specified coordinates.
- Start, pause, resume, and cancel building tasks.
- View task progress and connection status.
- Detect stuck or failed building tasks.
- Report unsupported blocks and incomplete builds.
- Keep server configurations and task states separate.

## Target Environment

- Minecraft Java Edition
- Initial target: Minecraft 1.20.4
- Initial server software: PaperMC
- Cloud-based Linux runtime
- GitHub repository for project source code
- Browser-based dashboard
